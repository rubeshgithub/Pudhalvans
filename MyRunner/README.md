# My Runner
**by Pudhalvans Games**

A modern, stylish vertical running game where you race upwards against a bot opponent!

## 🎮 Gameplay

Race vertically upwards in a 3-lane track. Hold UP ARROW to run and press SPACE to jump between lanes. Reach the finish line before your bot opponent to win!

## ✨ Features

### 🏃 Play Mode
- **Vertical Running**: Run upwards, not sideways!
- **Manual Controls**: Hold UP ARROW to accelerate, release to slow down
- **Lane Jumping**: Press SPACE to cycle through lanes (or use LEFT/RIGHT arrows)
- **1v1 Racing**: Compete against one bot opponent
- **Progressive Difficulty**: Bots get faster with each level
- **Modern UI**: Sleek, stylish interface with real-time stats

### 👕 Character Customization
- **Username**: Set your custom username (displayed above your character)
- **Hair Colors**: 6 different colors to choose from
- **Shirt Colors**: 6 vibrant options
- **Pants Colors**: 6 stylish choices
- **Accessories**: Cap, glasses, headband, watch, or none
- **Live Preview**: See your character in real-time
- **Auto-Save**: All customizations saved automatically

### 💪 Training Mode
- **Speed Upgrades**: Each training session adds +15 speed
- **Visual Feedback**: Animated effects when training
- **Track Progress**: See your current speed stat

## 🎯 Controls

- **UP ARROW**: Hold to run (accelerate)
- **SPACE**: Jump to next lane (cycles through 3 lanes)
- **LEFT/RIGHT ARROWS**: Jump to specific lane
- **MOUSE**: Navigate menus

## 🏆 How to Win

1. Hold UP ARROW to build speed and run upwards
2. Use SPACE or LEFT/RIGHT to dodge and change lanes
3. Reach the finish line before the bot
4. Earn trophies and advance to harder levels
5. Train to increase your max speed

## 🎨 Modern Design

- Dark gradient backgrounds with neon accents
- Grid-based futuristic aesthetic
- Smooth animations and transitions
- Glowing text effects
- Real-time speed and position tracking

## 🚀 Getting Started

Simply open `index.html` in a modern web browser to play!

## 💾 Progress Saving

Your progress, trophies, character customization, and speed upgrades are automatically saved to your browser's localStorage.
